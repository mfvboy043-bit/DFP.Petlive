# UI review
Verdict: conditional

Candidate stays in Petlive’s leaf / paper / Noto language (no purple-indigo, cream-terracotta, or broadsheet clichés). Imaging is correctly a timeline companion to Rx, not a new card-hero. Emergency X-Ray is enabled and parallel to labs. Lightbox captions use X-Ray / 超音波 keys, not Rx bag labels.

## Findings
- [UI-001] [P2] timeline clinic row — 藥單 + 影像 are two 24px pills in a `flex-shrink: 0` cluster beside clinic + year. Wrap exists, but on ~360px and in EN (`Rx photos` + `Imaging`) the clinic name and year split earlier than the Rx-only mainline; adjacent 24px targets with 6px gap invite mis-taps. — On narrow screens, put `.tl-visit-actions` on its own row under the clinic (full-width wrap), keep short collapsed labels, and add a little more gap or min-height so 藥單 / 影像 don’t share one fat-finger zone.
- [UI-002] [P2] timeline toggles — Open state for both chips is the same filled leaf pill with the same copy (`收合` / `Hide` / `閉じる` / `접기`). With both panels expanded, the two controls are indistinguishable. — Keep type in the open label (e.g. 收合影像 / Hide imaging) or a second visual cue so the chips still parse as 藥單 vs 影像.
- [UI-003] [P2] expand panel — Empty (and filled) imaging panel stacks the real upload/update `med-proof-btn` with a same-class disabled「上傳影片」plus「即將開放」. Two sibling CTAs, one dead, compete with the empty-state upload. Video copy is already on `imaging-proof`. — Leave thumbs, figcaption, clear, and one upload CTA in the panel; keep the coming-soon video control on the form only (muted hint, not a second button).
- [UI-004] [P2] imaging-proof hierarchy — Screen `h2` and archive kicker are the same string in zh / ja / ko (`本次就診影像` / `この来院の画像` / `이번 진료 영상`). Med-proof separates action title (`補上佐證照片`) from visit kicker (`本次就診佐證`). Clinic + date in the plate then repeat the job of the title. — Make the heading an action (`補傳影像` / Add imaging) and keep the kicker as visit target, or drop the kicker and let h3 clinic + date carry identity.
- [UI-005] [P2] imaging-proof previews — Slot previews are 88×88 `lab-photo-fig` crops with `proof-clear-btn` still `position: absolute` (and `width: 100%`), so「移除」overlays the radiograph instead of sitting under it. Hard to read X-Ray/US stills and easy to hit Remove while scanning. — Use larger stills (med-proof `proof-preview` scale) or reset the clear button to a below-thumb control; don’t cover the image.
- [UI-006] [P3] thumbs / lightbox — Timeline thumbs reuse `cursor: zoom-in` and type figcaptions (good); lightbox title follows `imagingXrayCaption` / `imagingUsCaption`. On phone there is no zoom glyph, and figcaption has no CSS (UA italic). — Add a light zoom mark or keep caption styled like `.tl-visit-rx-kicker`; optional type grouping (X-Ray row / 超音波 row) if 8 thumbs land in one grid.
- [UI-007] [P3] summary list — Date → clinic → types is a clear, light list; empty hint + 前往時間軸 is right. Rows are tappable cards (allowed) but have no chevron, hover/pressed, or “opens timeline” cue, so they read like static lab items. — Add a trailing affordance or one-line hint that tap jumps to that visit’s imaging panel.
- [UI-008] [P3] emergency docs — Enabled X-Ray tile matches labs; subtitle empty vs `最近 {date} · {types}` is correct. Mobile lets `small` wrap; desktop `white-space: nowrap` + ellipsis can clip the types on the half-width tile. — Allow wrap (or put types on a second line) at the default e-docs size too.
