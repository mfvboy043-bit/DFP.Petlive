## Findings
- [MED-001] [medium] `domains/emergency/adapters.js` `deriveActiveEmergencyMeds` → C `formatMedDose` / copy `formatMedLine` — Compound flatten correctly expands ingredients and skips empty names, but each row inherits parent `frequency` while dose lives only in free-text `ing.dose` (demo data e.g. `12.5 mg · …`). `formatMedDose` returns frequency-only when structured amount/unit are absent and never falls through to `med.dose`, so emergency card and copy can omit mg/ml amounts for active compound ingredients. Residual adjacency; out of EM HTML-stay scope. Suggested fix (advisory): later show the same source tags as timeline if Victor wants passport-level source clarity on the card.

Preserved parity, not new authority. Suggested fix (advisory): document limitation; extend parse only with explicit product rules, do not invent durations.
